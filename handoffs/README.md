# Handoffs

Only handoffs attached to a ticket belong here. Write a session handoff outside
the repository first, at `~/.local/state/agent-handoffs/tuohi/`, and promote a
snapshot here when a ticket needs it, naming the ticket and the commit it was
written against.

A handoff is orientation, not a second ledger: status and rationale live in the
tickets. Read the current source and tickets before trusting a snapshot. Never
put credentials or authentication output in one.
