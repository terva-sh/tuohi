## Description

Add an explicit macOS bundle artifact/install mode rather than replacing a sealed app executable. Extract a signed ZIP into a private stage with bounded entries/expanded size and reject traversal, duplicate paths, unsafe symlinks and unexpected roots. Preserve safe framework symlinks and executable modes. Reject package-managed modes and unsupported platforms; no installer elevation or signing/notarization service is added.
